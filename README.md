# Door Lock

2019-2021 code for two versions of a door lock system!

## Version 1: Arduino

- `rfid.ino` is code for the main Arduino
- `display_2.ino` is code for the secondary display Arduino

## Version 2: Raspberry Pi

- `rfid_client_pi3.py` and `rfid_client_pi4.py` are the secondary display programs for the Pi 3B+ and 4B respectively
- `rfid_server_pi3.py` and `rfid_server_pi4.py` are the main programs for the Pi 3B+ and 4B respectively
